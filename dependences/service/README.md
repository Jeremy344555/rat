# Публикация RAT в Docker

В каталоге расположены файлы для публикации RAT из локальной базы с использованием Docker.

Для запуска RAT в Docker необходимо:

* Создать файл `.env` в текущем каталоге
* Указать в нем значения переменных
  
  ```properties
  PLATFORM_PATH=<Путь к файлам установленной платформы>
  INFOBASE_PATH=<Путь к файловой информационной базе>
  HASP_INI=<Путь к файлу настроек nethasp.ini>
  ```

* Запустить сервис `docker compose up`
* Для запуска сервиса с пересборкой (изменились параметры Dockerfile или конфигов httpd/vrd) `docker compose up --no-deps --build apache-1c`
