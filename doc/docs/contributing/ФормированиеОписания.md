# Формирование описания API

Одним из сложных моментов при разработке сервиса является генерация описания API.

Расширение содержит 2 модуля для работы с описанием

* `РатOpenAPI` - Является оберткой над OpenAPI, содержит конструкторы объектов описания
* `РатСпецификация` - Попытка облегчить процесс создания операций
